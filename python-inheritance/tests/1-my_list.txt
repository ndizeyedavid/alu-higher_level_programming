Test cases for MyList class with print_sorted.

>>> import sys
>>> sys.path.insert(0, 'python-inheritance')
>>> MyList = __import__('1-my_list').MyList
>>> my_list = MyList()
>>> my_list.append(1)
>>> my_list.append(4)
>>> my_list.append(2)
>>> my_list.append(3)
>>> my_list.append(5)
>>> print(my_list)
[1, 4, 2, 3, 5]
>>> my_list.print_sorted()
[1, 2, 3, 4, 5]
>>> print(my_list)
[1, 4, 2, 3, 5]

Test print_sorted with negative numbers.

>>> my_list = MyList()
>>> my_list.append(-5)
>>> my_list.append(3)
>>> my_list.append(-2)
>>> my_list.append(0)
>>> my_list.append(-8)
>>> my_list.print_sorted()
[-8, -5, -2, 0, 3]

Test print_sorted with empty list.

>>> my_list = MyList()
>>> my_list.print_sorted()
